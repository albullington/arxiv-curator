## [PAST-Bench: Benchmarking the Foundations of Recursive Self-Improvement in Personal Agents](https://arxiv.org/abs/2608.04003v1)
**Score:** 0.955  |  **arXiv:** 2608.04003v1

**PAST-Bench** is a new benchmark featuring 26 scenarios designed to evaluate whether personal AI agents systematically improve over time by leveraging saved context across sessions. Evaluating multiple models and frameworks, the authors find that while retained experience does yield performance gains, these improvements are highly uneven and frequently fail to use the intended save, retrieve, and update mechanisms. To address these gaps, the authors introduce **Hermes+**, a modified agent framework that significantly enhances experience-driven performance, particularly on tasks requiring agents to overwrite outdated information.

## [Structured Memory for Edge Language Models: Persistent Context and Corpus Retrieval via O(1) SSM State Injection](https://arxiv.org/abs/2608.02560v1)
**Score:** 0.916  |  **arXiv:** 2608.02560v1

This paper introduces a technique for State-Space Models (SSMs) that eliminates context prefill overhead in retrieval-augmented generation (RAG) by pre-encoding documents into persistent hidden states and injecting them at query time in $O(1)$ time. Evaluated on a 1.2B-parameter edge language model, the approach matches standard RAG accuracy while reducing prefill latency from 27 seconds to under 6 milliseconds—a ~4,500x speedup. Researchers interested in ultra-fast on-device LLMs or persistent agent memory should read this to see how non-Transformer backbones can enable instant context retrieval.

## [ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://arxiv.org/abs/2607.29677v1)
**Score:** 0.915  |  **arXiv:** 2607.29677v1

**Summary:**

ExtractBench is a new open-source benchmark containing 4,869 enterprise document pages designed to evaluate schema-guided extraction agents across value accuracy, record completeness, source grounding, and computational cost. Benchmarking reveals significant trade-offs: commercial vision-language models struggle with long-document list truncation, while coding agents are accurate but expensive. The authors demonstrate that specialized agentic workflows (such as LlamaExtract Agentic Plus) can achieve top-tier extraction accuracy and traceability at a fraction of the cost of coding agents.

Evaluated on three benchmarks, it offers researchers a novel self-distillation method to solve fine-grained credit assignment in long-horizon reasoning tasks.

## [SocietyBench: Forecasting Counterfactual Social-World Evolution](https://arxiv.org/abs/2608.04009v1)
**Score:** 0.904  |  **arXiv:** 2608.04009v1

**SocietyBench** is a new benchmark designed to evaluate how well LLMs and AI agents can forecast the evolution of complex, real-world social events and public opinion dynamics over time. To prevent models from relying on pre-training memory, it converts news and social media timelines into anonymized, date-shifted "counterfactual social worlds" and scores predictions on both probability calibration and temporal accuracy. Experiments reveal that top frontier LLMs achieve only 75/100, existing agent frameworks fail to improve base model scores, and a model's calibration ability is often completely decoupled from its temporal accuracy.

## [The Parts Are Greater Than the Sum: Automated Task Sequencing for Efficient Training of Multi-Policy LLMs](https://arxiv.org/abs/2607.29601v1)
**Score:** 0.892  |  **arXiv:** 2607.29601v1

To prevent task interference and catastrophic forgetting during multi-task fine-tuning, this paper introduces an automated framework that groups and sequences tasks into separate QLoRA adapters. By routing compatible tasks along decoupled optimization paths within a fixed parameter budget, the method preserves positive transfer between tasks more effectively than simply increasing adapter size. Experiments on the TRACE benchmark demonstrate that this multi-policy approach achieves superior performance compared to standard single-adapter PEFT methods.
