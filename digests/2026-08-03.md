## [ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://arxiv.org/abs/2607.29677v1)
**Score:** 0.915  |  **arXiv:** 2607.29677v1

**Summary:**

ExtractBench is a new open-source benchmark containing 4,869 enterprise document pages designed to evaluate schema-guided extraction agents across value accuracy, record completeness, source grounding, and computational cost. Benchmarking reveals significant trade-offs: commercial vision-language models struggle with long-document list truncation, while coding agents are accurate but expensive. The authors demonstrate that specialized agentic workflows (such as LlamaExtract Agentic Plus) can achieve top-tier extraction accuracy and traceability at a fraction of the cost of coding agents.

## [The Parts Are Greater Than the Sum: Automated Task Sequencing for Efficient Training of Multi-Policy LLMs](https://arxiv.org/abs/2607.29601v1)
**Score:** 0.892  |  **arXiv:** 2607.29601v1

To prevent task interference and catastrophic forgetting during multi-task fine-tuning, this paper introduces an automated framework that groups and sequences tasks into separate QLoRA adapters. By routing compatible tasks along decoupled optimization paths within a fixed parameter budget, the method preserves positive transfer between tasks more effectively than simply increasing adapter size. Experiments on the TRACE benchmark demonstrate that this multi-policy approach achieves superior performance compared to standard single-adapter PEFT methods.

## [TokTier: Exact Stateful Tokenization for Agentic LLM Serving](https://arxiv.org/abs/2607.29678v1)
**Score:** 0.882  |  **arXiv:** 2607.29678v1
**Length:** 24 pages

**Summary for Researchers:**

TokTier addresses the growing bottleneck of re-tokenizing long, incremental transcripts in agentic LLM workloads by providing a stateful, 100% exact tokenization service. It dramatically accelerates prompt continuations by re-tokenizing only a small window around appended text with a stable-boundary check, while routing new requests to a novel, highly parallel GPU-accelerated BPE tokenizer. Evaluated on real-world agent traces without token divergence, TokTier reduces tokenization latency to ~1 ms for multi-million character contexts, lowering median Time-To-First-Token in vLLM by 16–34% and enabling significantly higher serving throughput.

## [ResKV: Reconstructing Omitted Attention Contributions for Fixed-Budget KV Cache Compression](https://arxiv.org/abs/2607.29591v1)
**Score:** 0.878  |  **arXiv:** 2607.29591v1

**ResKV** improves fixed-budget KV cache compression by splitting memory into an exact main cache and a compact "residual cache" that mathematically reconstructs the attention contributions of omitted tokens directly within softmax normalization. It dynamically allocates residual capacity across layers and heads while using query-level gating during decoding to fine-tune these contributions on the fly. Evaluated on benchmarks like LongBench and RULER, ResKV consistently outperforms existing eviction and merging baselines across multiple LLM backbones without sacrificing memory efficiency or decoding throughput.

## [When Does On-Policy Interaction Help? Representational Tradeoffs in Value-Based Imitation Learning](https://arxiv.org/abs/2607.29617v1)
**Score:** 0.877  |  **arXiv:** 2607.29617v1

This paper demonstrates that combining on-policy interaction with value-based imitation learning relaxes expressiveness requirements, allowing a learner to succeed as long as it can represent the expert's value function rather than its full policy. The authors introduce an interactive algorithm called OVI and theoretically prove that interaction is necessary to avoid scaling with the complexity of the expert policy class. Empirically, OVI outperforms standard offline and policy-based methods like BC and DAgger, achieving its largest gains when the learner network is substantially less expressive than the expert.

## [QASP: Query-Adaptive Robust Vector Search Policy](https://arxiv.org/abs/2607.29606v1)
**Score:** 0.858  |  **arXiv:** 2607.29606v1
**Length:** 12 pages

**QASP** addresses performance variance in vector search by using a single upfront regression model to predict each query's entire recall progression curve. From this curve, it dynamically determines the optimal search depth for any recall target across different datasets and index types without requiring repeated model calls or retraining. In experiments, QASP dramatically lowers per-query recall variance and cuts data access by 80% while maintaining 99% recall.

**Score:** 0.840  |  **arXiv:** 2607.29592v1
**Length:** 21 pages

This paper reveals that Out-of-Distribution (OOD) detection degradation in continual learning is primarily driven by cross-task score miscalibration rather than a loss of discriminative feature structure. Evaluated across standard CIFAR and ImageNet benchmarks, TOOD substantially improves OOD detection over existing baselines without requiring model retraining, making it particularly valuable for researchers working on robust, long-term continual learning systems.

Across 149 simulation tasks and seven real-world manipulation experiments, WCM achieves state-of-the-art performance with particularly strong out-of-distribution generalization.
