## [MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents](https://arxiv.org/abs/2610.06830v1)
**Score:** 0.983  |  **arXiv:** 2610.06830v1

This paper introduces **MemPilot**, a framework that dynamically balances performance, cost, and latency when managing multimodal memory for LLM agents. Using a multi-step reinforcement learning policy, it decides at runtime whether to retrieve pre-indexed memory or delegate query-specific curation of raw multimodal history to various LLMs and vision-language models. Evaluated across five benchmarks, MemPilot consistently achieves broader and more flexible efficiency–accuracy trade-off frontiers than existing memory baselines.

## [Agent in a Bottle: Can LLM Agents Turn Their Capabilities Into Cheap, Scalable Artifacts?](https://arxiv.org/abs/2610.08775v1)
**Score:** 0.922  |  **arXiv:** 2610.08775v1

This paper introduces BOTTLED, a benchmark that evaluates whether LLM agents can autonomously build cheaper, reusable artifacts—such as training a smaller model or writing code—to process large, repetitive workloads under strict budgets. The authors find that strong zero-shot model performance does not reliably translate to effective "bottling," with agents frequently underperforming standard distillation baselines. However, when successful, the approach can slash inference costs by over 600x with only modest drops in accuracy, offering a promising framework for cost-effective scaling.

## [IdeaAnchor: Teaching LLMs to Turn Literature into Research Ideas](https://arxiv.org/abs/2610.08781v1)

The authors train models using demonstration, self-distillation, and reinforcement learning, further augmenting the generation process with retrieval at inference time. Experimental results show consistent gains in ideation quality, demonstrating that anchor-based training drives creative synthesis while retrieval enhances detailed elaboration.

## [Recursive Video In-Context Learning for Agentic Robot](https://arxiv.org/abs/2610.06843v1)
**Score:** 0.914  |  **arXiv:** 2610.06843v1

This paper introduces Recursive Video In-Context Learning (RV-ICL), a training-free method that enables robotic LLM agents to effectively leverage demonstration videos without overloading their context windows. Rather than ingesting an entire video or static keyframes, the agent uses read-only tools to navigate a hierarchical representation of the demo, viewing coarse overviews for high-level planning and querying fine-grained video clips only when executing precise contact steps. Using just one demonstration per task, RV-ICL significantly boosts manipulation success rates on the LIBERO-PRO (96.5%) and LIBERO-Plus (95.8%) benchmarks.

## [CLIFT: Conformal Self-Verification for Web Agent Training and Test-Time Scaling](https://arxiv.org/abs/2610.06829v1)
**Score:** 0.908  |  **arXiv:** 2610.06829v1

CLIFT addresses the high cost and sparsity of using external LLM judges to supervise web agents by introducing a conformal self-verification framework. It enables agents to self-answer certified verification questions to generate dense per-step training rewards, then reuses this question bank at test time to rerank and select the best trajectory across retries without external supervision. The method achieves state-of-the-art results on WebArena Infinity and VisualWebArena, demonstrating an effective way to convert expensive judge feedback into a reusable, judge-free signal for both RL training and test-time scaling.

## [Reinforcement Learning with Conformal Action Sets: An Application to Sequential Recommendation](https://arxiv.org/abs/2610.08743v1)
**Score:** 0.908  |  **arXiv:** 2610.08743v1

This paper introduces Reinforcement Learning with Calibrated Pruning (RLCP), an approach that dynamically sizes recommendation slates during a session by pruning unpromising actions using critic scores and an online calibrated threshold. The authors provide finite-session theoretical guarantees, bounding both proxy target miss rates and overall reward loss without assuming model parameter convergence. On standard recommendation benchmarks, RLCP dramatically increases catalog diversity (up to 5.2× over RL baselines) while maintaining competitive session depth without expanding set sizes.

## [One Figure, Every Canvas: Editable Flowchart Relayout via Agentic Pipeline](https://arxiv.org/abs/2610.06852v1)
**Score:** 0.893  |  **arXiv:** 2610.06852v1

This paper tackles the challenge of automatically reshaping raster ML flowcharts to fit diverse aspect ratios (e.g., slides, posters, or social media) without hallucinating content or breaking graph connections. The authors propose an agentic pipeline with built-in critic checks that combine deterministic rules and vision-language model feedback to generate structurally faithful, editable draw.io (XML) files. On a benchmark of 100 flowcharts across five target ratios, the method achieves 68.6% content fidelity, significantly outperforming existing image-generation and parsing baselines (11.2–41.4%).

## [Towards Looped Models Done Right, Part II: Rethinking at Fixed Points](https://arxiv.org/abs/2610.06833v1)
**Score:** 0.889  |  **arXiv:** 2610.06833v1

This paper shows that encouraging recurrent states to converge toward fixed points in looped language models significantly reduces computational costs across training, inference, and reinforcement learning. To achieve this, the authors introduce an entropy-regularized, learned depth prior alongside an orthogonal input injection mechanism to better shape the recurrent dynamics. Evaluated from 100M to 1.6B parameters, their approach consistently lowers perplexity and matches the downstream performance of standard fixed-depth baselines while using a 3x smaller KV cache.

## [MRVQ: One Resident Index for Dimension- and Rate-Elastic Vector Search](https://arxiv.org/abs/2610.03651v1)
**Score:** 0.883  |  **arXiv:** 2610.03651v1

This paper introduces Matryoshka Residual Vector Quantization (MRVQ), a method that allows a single stored index to dynamically adapt to varying bit-rates and embedding dimensions simply by truncating its codes. By serving all operating points from one artifact, MRVQ cuts index RAM by roughly 18–22× compared to maintaining separate per-rate indices and outperforms standard baselines like PQ and OPQ. While it trades off some retrieval accuracy compared to specialized, separately tuned models, it offers a practical, low-memory solution for production retrieval systems needing elastic latency and memory budgets.
