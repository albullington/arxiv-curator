## [Structured Memory for Edge Language Models: Persistent Context and Corpus Retrieval via O(1) SSM State Injection](https://arxiv.org/abs/2608.02560v1)
**Score:** 0.916  |  **arXiv:** 2608.02560v1

This paper introduces a technique for State-Space Models (SSMs) that eliminates context prefill overhead in retrieval-augmented generation (RAG) by pre-encoding documents into persistent hidden states and injecting them at query time in $O(1)$ time. Evaluated on a 1.2B-parameter edge language model, the approach matches standard RAG accuracy while reducing prefill latency from 27 seconds to under 6 milliseconds—a ~4,500x speedup. Researchers interested in ultra-fast on-device LLMs or persistent agent memory should read this to see how non-Transformer backbones can enable instant context retrieval.

**Summary:**

ExtractBench is a new open-source benchmark containing 4,869 enterprise document pages designed to evaluate schema-guided extraction agents across value accuracy, record completeness, source grounding, and computational cost. Benchmarking reveals significant trade-offs: commercial vision-language models struggle with long-document list truncation, while coding agents are accurate but expensive. The authors demonstrate that specialized agentic workflows (such as LlamaExtract Agentic Plus) can achieve top-tier extraction accuracy and traceability at a fraction of the cost of coding agents.

**Score:** 0.882  |  **arXiv:** 2607.29678v1

**Summary for Researchers:**

TokTier addresses the growing bottleneck of re-tokenizing long, incremental transcripts in agentic LLM workloads by providing a stateful, 100% exact tokenization service. It dramatically accelerates prompt continuations by re-tokenizing only a small window around appended text with a stable-boundary check, while routing new requests to a novel, highly parallel GPU-accelerated BPE tokenizer. Evaluated on real-world agent traces without token divergence, TokTier reduces tokenization latency to ~1 ms for multi-million character contexts, lowering median Time-To-First-Token in vLLM by 16–34% and enabling significantly higher serving throughput.

## [ResKV: Reconstructing Omitted Attention Contributions for Fixed-Budget KV Cache Compression](https://arxiv.org/abs/2607.29591v1)
**Score:** 0.878  |  **arXiv:** 2607.29591v1

**ResKV** improves fixed-budget KV cache compression by splitting memory into an exact main cache and a compact "residual cache" that mathematically reconstructs the attention contributions of omitted tokens directly within softmax normalization. It dynamically allocates residual capacity across layers and heads while using query-level gating during decoding to fine-tune these contributions on the fly. Evaluated on benchmarks like LongBench and RULER, ResKV consistently outperforms existing eviction and merging baselines across multiple LLM backbones without sacrificing memory efficiency or decoding throughput.
