## [Logos: An Agent Harness on a Cross-Process Bus](https://arxiv.org/abs/2608.28553v1)
**Score:** 0.849  |  **arXiv:** 2608.28553v1

Traditional AI agent frameworks typically execute all capabilities within a single process, causing an entire system and all active sessions to fail if a single component crashes. To solve this, the authors introduce **Logos**, a ROS-inspired harness that isolates plugin capabilities into independent, cross-process nodes communicating strictly via an append-only transcript. Empirical tests demonstrate that Logos successfully contains faults to individual nodes and allows agent sessions to seamlessly resume after crashes without duplicating tool side effects.

## [DARTS: Decoder-Aware Representation Tuning via Surgery for Model Merging](https://arxiv.org/abs/2608.28547v1)
**Score:** 0.846  |  **arXiv:** 2608.28547v1

This paper addresses representation bias in merged autoregressive LLMs, where hidden-state drift accumulates across sequence positions and degrades generation quality at critical decision points. To resolve this, the authors propose DARTS, a lightweight method that applies position-dependent corrections using an entropy-weighted loss to prioritize high-impact tokens. Evaluated on Llama-2-7B across coding, math, and instruction-following benchmarks, DARTS significantly outperforms standard surgery baselines while adding only 0.1% extra parameters.
