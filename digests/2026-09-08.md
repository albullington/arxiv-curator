## [Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability](https://arxiv.org/abs/2609.05339v1)
**Score:** 0.939  |  **arXiv:** 2609.05339v1
**Length:** 18 pages

This paper evaluates how well different LLM agent memory formats—specifically raw text, RAG chunks, compressed notes, and fixed-schema knowledge graphs—survive when the underlying model is upgraded. The authors find that fixed-schema knowledge graphs transfer seamlessly across models, whereas natural-language notes suffer sharp performance shifts due to tight model coupling, and RAG systems require full re-embedding rather than mixed indices to avoid retrieval failures. Crucially, the study demonstrates that repairing degraded memory post-upgrade is largely ineffective unless the original raw source histories are retained.

## [Necessary or Sufficient? Evaluating LLM Explanations With Behavioural Evidence](https://arxiv.org/abs/2609.05385v1)
**Score:** 0.904  |  **arXiv:** 2609.05385v1

This paper investigates whether the "key factors" LLMs cite to explain their decisions genuinely reflect their actual behavior, evaluating them against criteria of necessity (changing a factor alters the outcome) and sufficiency (retaining it preserves the outcome). Across eight frontier models from the GPT, Claude, and Gemini families, the authors find only weak-to-moderate alignment between cited explanations and true causal influence, with unmentioned factors frequently having a stronger impact on outputs than cited ones. This work is highly relevant for researchers studying AI interpretability, safety, and auditing who want to know if self-generated LLM explanations can be trusted for agent oversight.

**Why this matches:** This paper aligns with your interest in LLM evaluation and ranking by proposing an approach to evaluate LLM explanations using behavioral evidence.

## [Distill Globally, Adapt Locally: Reasoning Distillation and Product-Type Test-Time Training for Scalable Trade-Up Recommendation](https://arxiv.org/abs/2609.05363v1)
**Score:** 0.898  |  **arXiv:** 2609.05363v1

To scale LLM-driven "trade-up" recommendations to massive catalogs, this paper distills an LLM teacher’s reasoning into a compact, non-generative classifier that runs strictly on precomputed product embeddings without runtime text generation. The framework also introduces a test-time adaptation method that uses few-shot examples to tailor the frozen student model to category-specific upgrade criteria. Overall, the approach achieves high recommendation accuracy (0.941 AUC) while being roughly 5,000× faster and 10,000× cheaper than direct LLM inference.

## [CUA-Universe: A Scalable and Dynamic Environment for Hybrid GUI+CLI Agents](https://arxiv.org/abs/2609.05374v1)
**Score:** 0.895  |  **arXiv:** 2609.05374v1
**Length:** 21 pages

The authors introduce **CUA-Universe**, an automated pipeline that turns 16 real desktop applications into hybrid GUI+CLI environments to overcome the visual blind spots of CLI-only agents and the high latency of GUI-only agents. The framework synthesizes diverse multi-modal tasks and collects verified trajectories that teach models when to use visual inspection versus fast command-line execution. A 9B model trained on this data achieved substantial gains in task success while slashing execution steps and token costs by up to ~60% on benchmarks like OSWorld.

## [Design Docs Are All You Need: An AI-native Machine-Learning Performance Tool](https://arxiv.org/abs/2609.05364v1)
**Score:** 0.891  |  **arXiv:** 2609.05364v1

This paper introduces SMART, a symbolic machine-learning performance-modeling framework that maintains natural-language design documents instead of code, using AI agents to regenerate the entire codebase from scratch when updates occur. By pairing a minimal symbolic intermediate representation (IR) with step-by-step worked examples in the docs, the framework reliably generates implementations that reproduce hand-audited models—such as DeepSeek-V3 on a TPU pod slice—to round-off precision. It is an essential read for researchers interested in AI-native software engineering and sustainable tooling for rapidly evolving ML systems.

## [Multi-Step Tool-Calling over Korean Open Public APIs: A Benchmark and a Data-Synthesis Recipe](https://arxiv.org/abs/2609.05395v1)
**Score:** 0.882  |  **arXiv:** 2609.05395v1
**Length:** 30 pages

To address the struggle open-source LLMs face with multi-step tool use, this paper introduces **KOPA-Bench**, a 145-task benchmark grounded in live Korean public APIs. The authors also propose **EDGE**, a synthesis framework that maps and verifies viable multi-tool trajectories via real API execution to generate high-quality training data. Using this data with reinforcement learning, the authors train a 9B model that nearly matches a 27B baseline on both KOPA-Bench and the standard Berkeley Function-Calling Leaderboard (BFCL).

## [RegionFed: Federated Learning for Personalized Query Understanding in Heterogeneous Retail Environments](https://arxiv.org/abs/2609.05403v1)
**Score:** 0.867  |  **arXiv:** 2609.05403v1

While conventional personalized federated learning methods catastrophically fail on modern transformers, RegionFed introduces an architecture-agnostic framework that personalizes models entirely at the gradient level. By using gradient conflict as a signal to diagnose data heterogeneity and adaptively tune personalization strength, it can be deployed on architectures like T5 and RoBERTa with zero model-code changes. Across diverse retail benchmarks, RegionFed matches the accuracy of privacy-violating centralized baselines while maintaining strong differential privacy ($\epsilon \approx 0.60$).

## [Molecular Déjà Vu: Digit-Level Retrieval of Published Values in Frontier Language Models](https://arxiv.org/abs/2609.05381v1)
**Score:** 0.863  |  **arXiv:** 2609.05381v1

This paper audits 22 frontier LLMs across 12 molecular property benchmarks and finds that strong performance is frequently driven by exact, digit-level retrieval of published values rather than genuine prediction. The authors show that increasing model reasoning levels actually amplifies this memorization, which often persists in top models even when molecular inputs are structurally transformed. Ultimately, suppressing this retrieval significantly closes the performance gap between models, making this a critical read for anyone evaluating or benchmarking LLMs on scientific data.

## [WearableQA: A Benchmark for Health Reasoning over Real-World Wearable Data](https://arxiv.org/abs/2609.05405v1)

It evaluates large language models across 16 question types that test both computational time-series analysis and physiological interpretation across single and multiple health signals. Evaluating 14 open-source and proprietary models revealed performance ranging from 19.6% to 72.9%—with most falling below 60%—demonstrating that longitudinal health reasoning remains an open and challenging frontier for AI.

## [The History Is the Detector: Executing CVE Patch History, End-to-End](https://arxiv.org/abs/2609.05335v1)
**Score:** 0.838  |  **arXiv:** 2609.05335v1

**BUGSTONE-E2E** is an automated framework that transforms historical CVE patch commits into executable detection rules to discover and repair similar, uncataloged vulnerabilities in other software. It uses a funnel-shaped pipeline that filters candidate code with fast syntactic heuristics before deploying LLM-guided agents and differential runtime testing to validate bugs and generate patches. In evaluations spanning thousands of high-severity CVEs, the system produced runtime-verified evidence for 644 vulnerabilities across 14 programs, demonstrating an effective end-to-end approach to automated vulnerability detection.
