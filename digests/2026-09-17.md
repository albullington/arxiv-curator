## [Cognitive Extensions for Dual-Process Language Agents: Memory and Self-Reflection in Interactive Environments](https://arxiv.org/abs/2609.19128v1)
**Score:** 0.935  |  **arXiv:** 2609.19128v1
**Length:** 13 pages

This paper enhances the dual-process SwiftSage agent for interactive environments by introducing two modular extensions: an adaptive episodic memory module (AMM) and an execution-time self-reflection module (SRM) for real-time error recovery. Tested on the ScienceWorld benchmark, the combined system significantly improves task success rates, overall scores, and step efficiency over the baseline. The authors find that runtime self-reflection provides the largest standalone benefit, suggesting that stabilizing execution control is a prerequisite for episodic memory to be fully effective.

## [Decomposition Buys Integrity, Not Yield](https://arxiv.org/abs/2609.17464v1)
**Score:** 0.920  |  **arXiv:** 2609.17464v1

Through theoretical modeling and production trace analysis, this paper demonstrates that hierarchical multi-agent architectures drastically reduce the amount of information that reaches the root agent, making flat architectures optimal for maximizing discovery ("yield"). Instead of improving findings, adding agent tiers acts as a trade-off that protects the root context from overflow and lowers compute costs at scale, but incurs heavy penalties in lost findings and alignment drift. Ultimately, the authors show that delegating tasks across agent hierarchies is mathematically justified in only 0.7% to 11.3% of real-world sessions, challenging core architectural folklore in multi-agent design.

## [Verifiable Social Reasoning for LLM Assistants](https://arxiv.org/abs/2609.17496v1)
**Score:** 0.906  |  **arXiv:** 2609.17496v1

The authors introduce **Fuse**, an open-source multi-agent simulation framework and 21,000-example benchmark that evaluates how well LLM assistants infer hidden social motives from subjective, user-mediated narratives with verifiable ground truth. Evaluating 12 LLMs, they find that models struggle with user mediation, are highly susceptible to biased user framing, and often fail to improve even when given longer multi-turn conversations to ask clarifying questions. ## [rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference](https://arxiv.org/abs/2609.19104v1)
**Score:** 0.897  |  **arXiv:** 2609.19104v1

**rMuscle** is an efficient inference framework for Vision-Language-Action (VLA) models that speeds up repetitive robotic tasks by caching internal model states, mimicking biological muscle memory. It introduces a dual-phase cache that reuses visual-token outputs and neuron activation patterns across similar executions, drastically cutting compute overhead and memory bandwidth demands. Evaluated on physical manipulation setups and standard benchmarks, it delivers a 1.29–1.42× inference speedup on edge and desktop GPUs without compromising task success rates.

## [What Breaks Under Pruning in Smart Homes, and When? Evaluating LLM Degradation Across Architectures and Task Complexity](https://arxiv.org/abs/2609.17515v1)
**Score:** 0.889  |  **arXiv:** 2609.17515v1

This paper systematically evaluates how model pruning impacts smart-home tool calling across dense and mixture-of-experts (MoE) architectures. The authors find that MoE models tolerate pruning significantly better than dense models, which degrade sharply and tend to develop systematic over-refusal. Crucially, pruning breaks fine-grained execution details (like specific arguments and values) long before high-level intent, demonstrating why evaluating pruned tool-calling agents requires looking beyond aggregate accuracy.

## [Playing log(N)-Questions over Wikipedia Abstracts: Communication Efficiency Between Paired Frontier Models](https://arxiv.org/abs/2609.19113v1)
**Score:** 0.882  |  **arXiv:** 2609.19113v1
**Length:** 29 pages

This paper evaluates self-communication efficiency in six frontier LLMs using an optimal $\log_2(N)$-questions game, testing how effectively paired instances of a model can identify a target Wikipedia abstract among up to 1,024 candidates. Most leading models achieve a predictable per-round reliability of ~93%—with losses split evenly between inaccurate answers and poor candidate bisection—while reasoning-token consumption shows little correlation with success. The highest-performing models maximize information gain by dynamically partitioning candidates based on document titles, whereas the weakest model suffers from a persistent bias toward answering "No."
