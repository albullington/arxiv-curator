## [ReCite: Agentic Reasoning for Faithful Citation](https://arxiv.org/abs/2609.09156v1)
**Score:** 0.951  |  **arXiv:** 2609.09156v1

Current automated citation tools often misattribute claims because they rely on surface-level semantic similarity rather than verifying whether a cited paper logically supports the author's statement. To resolve this, the authors introduce **ReCite**, a lightweight agentic framework that uses query planning and reflective, self-correcting verification loops to ensure claim-evidence consistency. Evaluated against much larger state-of-the-art generative models, ReCite achieves superior citation accuracy, making it a strong candidate for researchers seeking more dependable automated academic writing pipelines.

## [MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents](https://arxiv.org/abs/2609.09115v1)
**Score:** 0.944  |  **arXiv:** 2609.09115v1
**Length:** 15 pages

**MeClear** addresses the issue of long-horizon LLM agents retrieving outdated or conflicting memories that degrade downstream task performance. The framework uses a cooperative game-theoretic approach—combining Leave-One-Out screening with sampled Shapley attribution—to pinpoint and temporarily suppress harmful context memories on a per-query basis without altering the persistent memory store. Across ten long-dialogue benchmarks, it achieves an 82.3% task recovery rate, outperforming standard Leave-One-Out baselines by 25.5 percentage points.

## [Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability](https://arxiv.org/abs/2609.05339v1)
**Score:** 0.939  |  **arXiv:** 2609.05339v1
**Length:** 18 pages

This paper evaluates how well different LLM agent memory formats—specifically raw text, RAG chunks, compressed notes, and fixed-schema knowledge graphs—survive when the underlying model is upgraded. The authors find that fixed-schema knowledge graphs transfer seamlessly across models, whereas natural-language notes suffer sharp performance shifts due to tight model coupling, and RAG systems require full re-embedding rather than mixed indices to avoid retrieval failures. Crucially, the study demonstrates that repairing degraded memory post-upgrade is largely ineffective unless the original raw source histories are retained.

**Why this matches:** Given your interest in agent memory and preference for real experiments over pure theory, this paper presents a controlled study investigating whether an agent's memory remains portable across model upgrades. ## [Procedural Graphs: Self-Evolving Execution Structures for LLM Agents](https://arxiv.org/abs/2609.09153v1)
**Score:** 0.934  |  **arXiv:** 2609.09153v1
**Length:** 36 pages

To prevent LLM agents from losing track or making ordering errors during long-horizon tool use, this paper introduces the **Procedural Graph**, an execution structure that explicitly organizes procedural knowledge into step-by-step triplets to provide dynamic situational guidance. The graph is self-evolving, using an LLM-based loop that automatically refines and validates its own structure by comparing successful and failed agent trajectories. Across diverse benchmarks and models, this framework consistently outperforms standard memory-based baselines and matches or exceeds hand-designed workflows without requiring manual engineering.

## [Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails](https://arxiv.org/abs/2609.09134v1)
**Score:** 0.913  |  **arXiv:** 2609.09134v1

The authors find that when optimizing an agent’s harness (prompts, tools, and scaffolding) for a smaller model, fine-tuning that model on a stronger expert's full trajectories unexpectedly causes severe performance drops by disrupting the fit between the harness and the model's native planning style. To fix this, they introduce an automated on-policy correction pipeline where the expert rewrites only the specific failing turns within the smaller model's own rollouts. This targeted approach preserves model-harness compatibility, successfully compounding the performance benefits of both harness evolution and fine-tuning at low cost.

## [Necessary or Sufficient? Evaluating LLM Explanations With Behavioural Evidence](https://arxiv.org/abs/2609.05385v1)
**Score:** 0.904  |  **arXiv:** 2609.05385v1

This paper investigates whether the "key factors" LLMs cite to explain their decisions genuinely reflect their actual behavior, evaluating them against criteria of necessity (changing a factor alters the outcome) and sufficiency (retaining it preserves the outcome). Across eight frontier models from the GPT, Claude, and Gemini families, the authors find only weak-to-moderate alignment between cited explanations and true causal influence, with unmentioned factors frequently having a stronger impact on outputs than cited ones. This work is highly relevant for researchers studying AI interpretability, safety, and auditing who want to know if self-generated LLM explanations can be trusted for agent oversight.

**Why this matches:** This paper aligns with your interest in LLM evaluation and ranking by proposing an approach to evaluate LLM explanations using behavioral evidence.

## [Distill Globally, Adapt Locally: Reasoning Distillation and Product-Type Test-Time Training for Scalable Trade-Up Recommendation](https://arxiv.org/abs/2609.05363v1)
**Score:** 0.898  |  **arXiv:** 2609.05363v1

To scale LLM-driven "trade-up" recommendations to massive catalogs, this paper distills an LLM teacher’s reasoning into a compact, non-generative classifier that runs strictly on precomputed product embeddings without runtime text generation. The framework also introduces a test-time adaptation method that uses few-shot examples to tailor the frozen student model to category-specific upgrade criteria. Overall, the approach achieves high recommendation accuracy (0.941 AUC) while being roughly 5,000× faster and 10,000× cheaper than direct LLM inference.

The authors introduce **CUA-Universe**, an automated pipeline that turns 16 real desktop applications into hybrid GUI+CLI environments to overcome the visual blind spots of CLI-only agents and the high latency of GUI-only agents. The framework synthesizes diverse multi-modal tasks and collects verified trajectories that teach models when to use visual inspection versus fast command-line execution. A 9B model trained on this data achieved substantial gains in task success while slashing execution steps and token costs by up to ~60% on benchmarks like OSWorld.

## [ExecCritic: Learn to Test, Test to Improve for Coding Agents](https://arxiv.org/abs/2609.09133v1)
**Score:** 0.891  |  **arXiv:** 2609.09133v1
**Length:** 35 pages

**ExecCritic** addresses the issue of coding agents generating flawed, self-validating patches by decoupling test creation from code repair into two distinct, independently trained agent roles. Using role-specific reinforcement learning on an open-weight 35B model, a dedicated Test agent learns to write rigorous, discriminating tests, while a separate Repair agent learns to revise code strictly based on feedback from those frozen tests. On SWE-bench Verified, this approach improves task resolution from 61.2% to 72.6%, demonstrating significant gains without relying on larger models or oracle feedback at evaluation time.

**Why this matches:** This paper aligns with your interests in agents and LLM evaluation, specifically focusing on a test-driven approach ("Learn to Test, Test to Improve") for coding agents. It directly connects to your focus on agent architectures and practical evaluation techniques.
