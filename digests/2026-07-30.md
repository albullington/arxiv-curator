## [UniMem: Complementary Episodic-to-Parametric Memory for Boundary-Agnostic Task Streams](https://arxiv.org/abs/2607.26017v1)
**Score:** 0.936  |  **arXiv:** 2607.26017v1

**UniMem** is a self-routing memory framework designed to help LLM agents handle continuous, unlabeled task streams by balancing real-time adaptation with long-term stability. Inspired by human memory consolidation, it uses learnable routing tokens to store novel tasks in an episodic retrieval buffer while consolidating recurring execution patterns into expandable parametric memory blocks. Across long-horizon streaming benchmarks, UniMem consistently outperforms existing baselines by an average of 4.0 Exact Match points without requiring explicit task labels or causing unchecked parameter growth.

## [Eviction as Estimation: A Fixed-Lag Smoothing View of Test-Time Memory, and When Measuring Beats Accumulating](https://arxiv.org/abs/2607.24667v1)
**Score:** 0.929  |  **arXiv:** 2607.24667v1
**Length:** 8 pages

This paper reframes LLM KV-cache eviction as a fixed-lag estimation problem, introducing a training-free policy (RMM) that waits a few steps to retain tokens based on their observed near-future utility rather than past attention alone. While this delayed-measurement approach drastically improves memory efficiency in controlled settings with sharp token reuse, it performs similarly to standard baselines (like H2O) on natural text benchmarks where model attention is broad and diffuse. Researchers should read this paper for its theoretical framework explaining *when* measuring actual token usage outperforms accumulating attention, rather than for a new state-of-the-art benchmark winner.

## [A corrective agentic hybrid RAG and an operations-grounded evaluation for a scientific facility](https://arxiv.org/abs/2607.24663v1)

This paper introduces APS-RAG, a deployed platform that combines vector, keyword, and knowledge-graph retrieval to help staff query decades of diverse operational data at the Advanced Photon Source scientific facility. Evaluating the system on a new 50-question domain benchmark reveals that a dedicated cross-encoder reranker is critical for performance—outperforming LLM-based relevance scoring by nearly 33%—while graph channels and corrective agentic loops provided only marginal gains. The authors open-sourced their codebase, evaluation harness, and benchmark methodology, offering a practical, transferable blueprint for deploying trustworthy AI assistants in large scientific or industrial facilities.

## [Can AI agents conduct open-ended AI research? Early evidence from two case studies](https://arxiv.org/abs/2607.27191v1)
**Score:** 0.921  |  **arXiv:** 2607.27191v1

To better evaluate AI agents on open-ended tasks, this paper introduces "shadow evaluations," where frontier models attempt the central research questions of unpublished NeurIPS submissions and are graded directly by the original human authors. Across two case studies, agents autonomously executed all the necessary software engineering but failed to make meaningful progress on the core research questions, leading to clear rejections by the human experts. The findings indicate that while current agents can handle the technical execution of AI research, they still lack the creative problem-solving, strategic decision-making, and high-level reasoning required for publishable science.

## [Spend Experts Where You Are Unsure: Confidence-Adaptive Routing for Mixture-of-Experts LoRA](https://arxiv.org/abs/2607.26052v1)
**Score:** 0.910  |  **arXiv:** 2607.26052v1

**Summary for Researchers:**

CARE is a parameter-free, drop-in routing method for MoE-LoRA that dynamically adjusts the number of active experts per token based on model uncertainty instead of using a fixed top-$k$. By treating the router's probability distribution as a confidence signal, it allocates fewer experts to easy tokens and more experts to complex or ambiguous ones. Across standard benchmarks on LLaMA-3.1-8B and Qwen2.5-7B, CARE outperforms fixed top-$k$ baselines at matched compute budgets while also significantly improving out-of-distribution detection.
