## [Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning](https://arxiv.org/abs/2609.38147v1)
**Score:** 0.924  |  **arXiv:** 2609.38147v1

Across long-horizon coding, formal proof, and multi-domain reasoning benchmarks, the approach outperforms standard direct-control baselines and frontier agents (e.g., scoring 71.5% on ProgramBench with GPT-5.5). You should read this paper if you are researching agent architectures or test-time compute scaling, particularly to see how structured meta-control enables agents to keep improving over long runs where standard methods plateau.

## [Learning Meta-Skills for Agent Harness Design in Test-Time AI4AI](https://arxiv.org/abs/2609.38143v1)
**Score:** 0.904  |  **arXiv:** 2609.38143v1
**Length:** 22 pages

This paper investigates how a frozen "Builder" model can improve a "Target" agent's performance by learning to design better execution environments (harnesses) rather than modifying model weights. The authors introduce "Meta-Skills"—principles learned from execution feedback that tell the Builder when and how to provide task support—which improve benchmark performance by up to 12 percentage points over baselines. Crucially, the findings demonstrate that teaching an agent to build better external scaffolding for itself offers a promising new pathway for test-time self-improvement.

## [Turbo Harness: Instance-Adaptive Harness Optimization](https://arxiv.org/abs/2609.40330v1)
**Score:** 0.894  |  **arXiv:** 2609.40330v1

Unlike traditional methods that apply a single, static harness across all tasks, **Turbo Harness** adapts agent harnesses to individual problem instances. It works by recycling artifacts from prior global optimization runs into a structured "playbook," which a trained editor model uses at test time to generate instance-specific harness patches. Evaluated across seven agent and software engineering benchmarks, this instance-adaptive approach consistently outperforms standard global harness baselines.

## [AdviSD: Learning to Advise Frontier LLMs via Targeted Multi-Turn Self-Distillation](https://arxiv.org/abs/2609.38142v1)
**Score:** 0.887  |  **arXiv:** 2609.38142v1

This paper introduces **AdviSD**, a framework for training a small "advisor" model to guide frozen frontier LLMs (such as Claude and Gemini) using natural-language feedback. To prevent noisy or inconsequential corrections from degrading the advisor's performance, AdviSD combines reinforcement learning with a selective self-distillation mechanism that retains only the updates that measurably impact the executor's behavior—without requiring extra executor rollouts. Across tool-use benchmarks, an 8B advisor trained with AdviSD consistently outperforms standard RL baselines and successfully generalizes across tasks and different executor model families.

## [Skill-Space Shooting for Autonomous Robot Policy Improvement](https://arxiv.org/abs/2609.38178v1)
**Score:** 0.884  |  **arXiv:** 2609.38178v1

To help deployed robots continuously improve without relying on human demonstrations, this paper introduces **skill-space shooting**, a framework that autonomously turns task failures into learnable corrections. The method uses foundation models to explore and compose reusable short-horizon skills when errors occur, converting successful recovery trajectories into training data for the underlying task policy. Real-world experiments show that this approach enables autonomous, scalable policy improvement and allows skills to be shared across tasks to minimize future supervision.

## [Scaling Laws for Looped Mixture of Experts](https://arxiv.org/abs/2609.40316v1)
**Score:** 0.877  |  **arXiv:** 2609.40316v1
**Length:** 19 pages

This paper introduces the first unified scaling law that jointly models recurrence (looped transformers) and sparsity (Mixture-of-Experts) alongside data and model size to guide compute- and memory-constrained architecture design. The framework accurately predicts held-out loss and reveals that looping and MoE sparsity offer complementary efficiency gains across active and total parameter budgets. Demonstrating this at a trillion-token scale, the authors show that an optimally looped MoE matches the reasoning performance of a non-looped MoE twice its size at the same training compute, while also enabling test-time compute scaling.

## [STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization](https://arxiv.org/abs/2609.38169v1)
**Score:** 0.873  |  **arXiv:** 2609.38169v1

Quantizing the recurrent states of linear attention models typically causes severe accuracy loss because errors compound over time and affect outputs unevenly across state dimensions. To fix this, the authors propose STEPQuant, a post-training quantization framework that allocates precision based on memory lifetime and scales key-value dimensions by their downstream output impact. On models up to 48B parameters, 6-bit STEPQuant matches full-precision accuracy while delivering over 5x state compression and cutting total serving memory by up to 68.7%.
