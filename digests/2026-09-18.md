## [Cognitive Extensions for Dual-Process Language Agents: Memory and Self-Reflection in Interactive Environments](https://arxiv.org/abs/2609.19128v1)
**Score:** 0.935  |  **arXiv:** 2609.19128v1
**Length:** 13 pages

This paper enhances the dual-process SwiftSage agent for interactive environments by introducing two modular extensions: an adaptive episodic memory module (AMM) and an execution-time self-reflection module (SRM) for real-time error recovery. Tested on the ScienceWorld benchmark, the combined system significantly improves task success rates, overall scores, and step efficiency over the baseline. The authors find that runtime self-reflection provides the largest standalone benefit, suggesting that stabilizing execution control is a prerequisite for episodic memory to be fully effective.

## [Decomposition Buys Integrity, Not Yield](https://arxiv.org/abs/2609.17464v1)
**Score:** 0.920  |  **arXiv:** 2609.17464v1

Through theoretical modeling and production trace analysis, this paper demonstrates that hierarchical multi-agent architectures drastically reduce the amount of information that reaches the root agent, making flat architectures optimal for maximizing discovery ("yield"). Instead of improving findings, adding agent tiers acts as a trade-off that protects the root context from overflow and lowers compute costs at scale, but incurs heavy penalties in lost findings and alignment drift. Ultimately, the authors show that delegating tasks across agent hierarchies is mathematically justified in only 0.7% to 11.3% of real-world sessions, challenging core architectural folklore in multi-agent design.

## [Semantic Action Graph: A Shared Representation for Agent Grounding and Human Interpretation of Sports Highlights](https://arxiv.org/abs/2609.20768v1)
**Score:** 0.909  |  **arXiv:** 2609.20768v1
**Length:** 5 pages

To address the difficulty of verifying and steering AI-generated video highlights, this paper introduces the *semantic action graph*, a lightweight schema that maps sports matches into connected players, actions, and moments. This shared representation simultaneously grounds generative AI agents that compose narrated highlights and powers a visual interface where viewers can inspect, search, and navigate the match. Tested on soccer fans via a prototype called SportSAGE, the system demonstrates that a single, human-readable graph can reliably bridge agent generation and human interpretability.

## [RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning](https://arxiv.org/abs/2609.20784v1)
**Score:** 0.907  |  **arXiv:** 2609.20784v1

**RetireOPD** improves reinforcement learning for multi-turn agents by using an RL-trained, skill-privileged teacher to provide dense token-level distillation to a skill-free student. Crucially, the student adaptively "retires" the teacher once their performance gap closes, continuing training purely with environment RL to avoid being held back by imperfect teacher guidance. Across ALFWorld and WebShop benchmarks using 1.5B–7B models, this approach boosts performance by 11% to 19% over standard RL baselines and consistently surpasses the privileged teacher itself.

## [An Empirical Study of Harness Design for Coding Agents](https://arxiv.org/abs/2609.20804v1)
**Score:** 0.900  |  **arXiv:** 2609.20804v1
**Length:** 43 pages

This paper systematically evaluates the individual components of coding agent harnesses—specifically context management, planning, and action spaces—across 176 experimental configurations on SWE-Bench and Terminal-Bench. The authors find that rule-based elision paired with summarization best prevents context overflow, planning primarily serves as a cost-cutter rather than an accuracy booster for strong models, and bash-proficient models operate more cheaply without custom tools. Read this paper if you want evidence-based, budget- and model-aware design principles for building more efficient autonomous software engineering agents.

## [rMuscle: Robotic Muscle Memory for Efficient Vision-Language-Action Model Inference](https://arxiv.org/abs/2609.19104v1)
**Score:** 0.897  |  **arXiv:** 2609.19104v1

**rMuscle** is an efficient inference framework for Vision-Language-Action (VLA) models that speeds up repetitive robotic tasks by caching internal model states, mimicking biological muscle memory. It introduces a dual-phase cache that reuses visual-token outputs and neuron activation patterns across similar executions, drastically cutting compute overhead and memory bandwidth demands. Evaluated on physical manipulation setups and standard benchmarks, it delivers a 1.29–1.42× inference speedup on edge and desktop GPUs without compromising task success rates.

## [Workspace Models: Lightweight Robotic Memory via Saliency-Driven Supervision](https://arxiv.org/abs/2609.20820v1)
**Score:** 0.892  |  **arXiv:** 2609.20820v1
**Length:** 26 pages

To eliminate the high latency and compute of querying vision-language models (VLMs) during robot deployment, this paper shifts VLM reasoning to training time to learn a compact latent memory called a "workspace token." The token distills only task-salient historical information via a VLM-supervised reconstruction loss, serving as a drop-in replacement for full observation histories. Validated in simulation and on real hardware, this lightweight representation removes the need for in-the-loop VLM inference while achieving superior policy performance on memory-intensive manipulation tasks.

This paper systematically evaluates how model pruning impacts smart-home tool calling across dense and mixture-of-experts (MoE) architectures. Crucially, pruning breaks fine-grained execution details (like specific arguments and values) long before high-level intent, demonstrating why evaluating pruned tool-calling agents requires looking beyond aggregate accuracy.
