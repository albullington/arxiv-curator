## [The Rise of Verbal Reinforcement Learning](https://arxiv.org/abs/2609.01597v1)
**Score:** 0.936  |  **arXiv:** 2609.01597v1

This survey introduces a unified framework for **Verbal Reinforcement Learning (VRL)**, a paradigm where natural language—rather than traditional scalar reward—serves as the primary feedback mechanism to improve AI agents. The authors organize existing literature into three core pillars based on how and when language operates: defining tasks (grounding), guiding test-time reasoning (deliberative feedback), and updating model weights during training (learning signal). It is a valuable read for researchers seeking a comprehensive taxonomy of language-based agent optimization alongside key open challenges in agent capability and alignment.

## [Retrieved but not ranked: surface-form bias in structural retrieval, from mathematics to agent trajectories](https://arxiv.org/abs/2609.01556v1)
**Score:** 0.908  |  **arXiv:** 2609.01556v1
**Length:** 18 pages

This paper shows that standard embedding models fail severely at structural retrieval—matching items based on underlying logic rather than wording—across both competition mathematics and embodied agent trajectories due to a strong bias toward surface-level lexical similarity. While LLM-based rerankers can partially mitigate this issue, their improvements vary widely across domains and rely partly on dataset memorization. Downstream experiments further reveal that this retrieval gap significantly limits retrieval-augmented setups, with oracle retrieval showing no measurable performance advantage over adversarially poor retrieval.

## [Efficient SWE Agent Benchmarking via Trajectory-Aware Evaluation](https://arxiv.org/abs/2609.01603v1)
**Score:** 0.906  |  **arXiv:** 2609.01603v1

Benchmarking software engineering agents is computationally expensive, and existing subset-based evaluation methods rely solely on pass/fail outcomes while ignoring the problem-solving process. To address this, the authors introduce PTA-IRT, a framework that incorporates agent execution trajectories—such as explored context and attempted code edits—to select more representative task subsets and better estimate agent ability. Under strict evaluation budgets, PTA-IRT consistently outperforms prior baselines in recovering overall benchmark scores and model rankings across four SWE datasets.

## [Adaptive Critical Token-Aware Retrieval for Repository-Level Code Generation](https://arxiv.org/abs/2609.01601v1)
**Score:** 0.900  |  **arXiv:** 2609.01601v1

While standard retrieval-augmented generation (RAG) approaches provide broad repository context, they often fail to address a few decisive "critical tokens" where generation errors tend to cascade. To solve this, the authors propose ACToR, a framework that dynamically identifies these critical positions during code generation to trigger on-demand, position-aware context retrieval. Tested on the RepoExec and CoderEval benchmarks, ACToR outperforms existing state-of-the-art methods by 8.4% and 15.4%, respectively, demonstrating that targeted retrieval at key decision points significantly mitigates functional failures.

## [Blog: Survey of Optimizers](https://arxiv.org/abs/2608.28557v1)
**Score:** 0.897  |  **arXiv:** 2608.28557v1

This survey categorizes modern deep learning optimization—spanning matrix-aware methods (such as Muon and Shampoo), schedule-free training, and memory-efficient quantized states—across four core design axes. It concludes that while matrix-level updates offer real progress, there is no universal replacement for AdamW because optimizer performance shifts heavily based on scale, batch size, compute constraints, and target metrics. Consequently, the paper provides a compositional framework for optimizer design and establishes a stricter protocol for benchmarking new optimization claims.

## [StudentSim: Training LLM-based Student Simulators](https://arxiv.org/abs/2609.01591v1)
**Score:** 0.885  |  **arXiv:** 2609.01591v1

The authors introduce **StudentSim**, a framework that trains individualized LLM-based student simulators capable of both accurately mirroring a learner's specific competence and realistically updating their behavior in response to tutor guidance. Evaluated across chess, mathematics, and English writing via a new benchmark (StudentSimEval), StudentSim consistently outperforms strong baselines in behavioral fidelity and responsiveness to instruction. Demonstrating its practical utility, using StudentSim as a reward model for reinforcement learning produced an AI tutor that human experts rated as significantly more accurate, personalized, and effective.

## [Selective Agent Guidance via Entropy: Learning Autonomous Policies from Imperfect VLM Teachers](https://arxiv.org/abs/2609.01567v1)
**Score:** 0.885  |  **arXiv:** 2609.01567v1
**Length:** 9 pages

This paper introduces **SAGE**, a framework that trains a lightweight reinforcement learning policy by querying an expensive, imperfect Vision-Language Model (VLM) teacher only when the agent is uncertain and weighting its advice using environment feedback. Evaluated on sparse-reward visual reasoning and navigation tasks, SAGE drastically cuts training query costs, operates with zero VLM calls at deployment, and learns autonomous policies that can even outperform the VLM teacher itself.
