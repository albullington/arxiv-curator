## [Rollplex: Cross-Phase GPU Spatial Sharing for Vision Language Model Post-Training](https://arxiv.org/abs/2608.14498v1)
**Score:** 0.924  |  **arXiv:** 2608.14498v1
**Length:** 16 pages

**Rollplex** is a post-training runtime for vision-language models (VLMs) that eliminates GPU underutilization caused by strictly sequential on-policy reinforcement learning phases. It achieves this by overlapping visual and prompt prefix computations with rollout decoding, using phase-aware memory management and layout-adaptive weight sharing to avoid memory overflow across different tensor-parallelism configurations. On 32 H800 GPUs, it preserves synchronous RL semantics while delivering up to a 1.30× speedup over serial execution and up to 2.24× over disaggregated baselines.

## [You Only Pass Once: Answering and Abstaining Together in a Single Forward Pass of a Frozen Language Model](https://arxiv.org/abs/2608.14465v1)
**Score:** 0.893  |  **arXiv:** 2608.14465v1
**Length:** 24 pages

This paper introduces **YOPO (You Only Pass Once)**, a method that resolves the activation interference that occurs when simultaneously applying activation steering (to improve reasoning) and probe-based abstention (to avoid confabulation when information is insufficient) in a frozen LLM. By using a lightweight network to reconstruct clean residual states from steered ones, YOPO accomplishes steering, answering, and abstaining in a single forward pass without doubling inference compute. Evaluated across multiple model families and question-answering benchmarks, YOPO outperforms both frozen and two-pass baselines while preserving robust zero-shot cross-domain abstention.

## [Split the Labor: Separating Evidence Interpretation from Decision Aggregation](https://arxiv.org/abs/2608.14509v1)
**Score:** 0.877  |  **arXiv:** 2608.14509v1
**Length:** 22 pages

This paper argues that multi-source reasoning pipelines should decouple evidence interpretation (via language models) from final decision aggregation (via calibrated arithmetic) using a standardized evidence interface. The authors identify a mathematical failure mode in standard score-summing approaches ("count-scale drift") and prove that pooling calibrated log-likelihood ratios resolves this issue across both LLMs and classical diagnostic systems. Empirical evaluations on longitudinal data demonstrate substantial performance gains (e.g., boosting AUPRC from 0.805 to 0.921) while clearly defining the framework's transferability and falsification criteria.

## [Twin: Playing an Unknown Game with a Test-Time Digital Twin](https://arxiv.org/abs/2608.14490v1)
**Score:** 0.857  |  **arXiv:** 2608.14490v1

This paper introduces **Twin**, a framework where an LLM coding agent infers the hidden rules and goals of unfamiliar games at test time by generating, validating, and iteratively repairing an executable programmatic world model. Evaluated on ARC-AGI-3 grid games, Twin drastically boosts base model performance from 7.8% to 93.3%, clearing 97.8% of levels while often exceeding human action efficiency. The findings suggest that on-the-fly code generation is an effective strategy for test-time world-model inference, shifting the primary challenge from environment modeling to goal discovery.

## [Marionette: Predicting World States, Rendering Geometry, Painting Appearance](https://arxiv.org/abs/2608.14530v1)
**Score:** 0.855  |  **arXiv:** 2608.14530v1

Instead of predicting video frames directly in pixel space, **Marionette** decouples interactive game world modeling into three explicit stages: predicting an interpretable 3D articulated state, rendering exact geometry using a fixed graphics bridge, and synthesizing photorealistic appearance with a video diffusion model. This explicit representation enables direct controllability and allows simple rule-based state corrections (e.g., fixing ground penetration and character drift) without modifying or retraining the visual synthesis model. Consequently, it achieves stable, long-horizon multi-entity simulation while maintaining high visual fidelity.
