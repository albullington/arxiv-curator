## [Vero: Can AI Agents Build Formally Verified Software Repositories?](https://arxiv.org/abs/2608.13522v1)
**Score:** 0.888  |  **arXiv:** 2608.13522v1

The authors introduce **Vero**, the first repository-level benchmark designed to evaluate whether AI agents can jointly generate multi-module code implementations and their machine-checked formal proofs in Lean 4. Built from real-world projects across domains like cryptography and distributed systems, the dataset features 43 multi-module instances alongside a specification-auditing mechanism. Empirical evaluations show that frontier agents struggle with repository-scale verification—solving only 27 of 43 tasks and failing entirely on the hardest ones—making Vero a challenging new testbed for trustworthy AI code generation.

## [QuoteBench: How Matched Scores Can Hide Command-Path Failures](https://arxiv.org/abs/2608.13547v1)
**Score:** 0.865  |  **arXiv:** 2608.13547v1
**Length:** 29 pages

**QuoteBench** introduces a benchmark to show that standard LLM agent evaluations often obscure severe execution-path failures—such as shell-escaping and reparsing errors—behind aggregate success scores. The authors demonstrate that intermediate interface quirks can slash task success rates by 55 to 73 percentage points, and that frontier model rankings shift significantly depending on how well each model adapts to the specific execution transport. Ultimately, the paper argues that coding agent benchmarks must explicitly document the entire execution pipeline and boundary contracts rather than treating execution scores as intrinsic model capabilities.

Furthermore, intervention experiments show strong semantic fidelity, with the model accurately reflecting vector arithmetic by combining or inverting explanations when feature directions are modified.

## [DARTree: Speculative Diffusion Decoding with Autoregressive Draft Trees](https://arxiv.org/abs/2608.13524v1)
**Score:** 0.839  |  **arXiv:** 2608.13524v1

**DARTree** is a training-free speculative decoding method that enhances diffusion-based draft generation by extending autoregressive (AR) correction from single token chains to full draft trees. It efficiently expands and scores tree nodes in parallel batches before pruning, ensuring candidate paths are causally conditioned without adding sequential latency overhead. Across math, code, and chat benchmarks, DARTree accepts up to ~13 tokens per verification step and achieves up to a 9.73× lossless speedup over standard autoregressive baselines.
